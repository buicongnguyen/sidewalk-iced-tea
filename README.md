# Sidewalk Iced Tea

Small browser game prototype for running an iced tea stall. Serve tables before customers run out of patience, earn coins, and buy upgrades.

## Play

GitHub Pages deploys the static client from `client/`:

https://buicongnguyen.github.io/sidewalk-iced-tea/

## Run Locally

```bash
cd client
npm install
npm start
```

Then open the local URL printed by the server.

## Smoke Test

```bash
cd client
npm install
npm run smoke
npm run flow
```

## Art

The playable build uses the generated PNG asset pack in `client/public/assets/final/`.
